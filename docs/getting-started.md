## Installation

Add Bast to an existing module:

```bash
go get github.com/bastion-framework/bast@latest
```

Or install the CLI to scaffold new projects:

```bash
go install github.com/bastion-framework/bast/cmd/bast@latest
```

---

## Scaffold a new project

The fastest path to a running Bast app:

```bash
bast new myapp
cd myapp
go mod tidy
go run .
```

This generates a fully working **Todo API** with:

- `GET /todos/` — list all todos (seeded with 2 items)
- `GET /todos/:id` — get a todo by ID
- `POST /todos/` — create a todo
- `PATCH /todos/:id` — update title / mark done
- `DELETE /todos/:id` — delete a todo
- `GET /health` — liveness probe
- `GET /ready` — readiness probe
- `GET /docs` — Swagger UI
- `GET /openapi.json` — raw OpenAPI 3.0 spec

Open [http://localhost:8080/docs](http://localhost:8080/docs) to test all endpoints interactively.

## Minimal app from scratch

If you prefer to wire everything yourself:

```go
// main.go
package main

import (
    "time"

    "github.com/bastion-framework/bast"
    "github.com/bastion-framework/bast/middleware"
)

func main() {
    app := bast.New(bast.Config{
        Port:         8080,
        ReadTimeout:  10 * time.Second,
        WriteTimeout: 30 * time.Second,
        IdleTimeout:  60 * time.Second,
    })

    app.Use(
        middleware.RequestID,
        middleware.Recover,
    )

    app.Register(helloModule())
    app.Listen()
}

func helloModule() bast.Module {
    return bast.Module{
        Prefix: "/hello",
        Controller: &helloController{},
    }
}

type helloController struct{}

func (c *helloController) Routes() []bast.Route {
    return []bast.Route{
        bast.GET("/:name", c.Hello),
    }
}

func (c *helloController) Hello(ctx *bast.Ctx) bast.Response {
    return ctx.OK(map[string]string{
        "message": "Hello, " + ctx.Param("name") + "!",
    })
}
```

```bash
go run .
# [Bast] Module     /hello              /hello
# [Bast]   GET      /hello/:name
# [Bast] Listening on :8080

curl http://localhost:8080/hello/world
# {"data":{"message":"Hello, world!"},"meta":null}
```

## Project layout

A project generated by `bast new` follows this structure:

```
myapp/
├── main.go                         # Boot, register modules, listen
├── go.mod
│
├── modules/
│   └── todos/
│       ├── todos.module.go         # Wires repo → service → controller
│       ├── todos.controller.go     # Route handlers only
│       ├── todos.service.go        # Business logic
│       ├── todos.repo.go           # Data layer — never imported externally
│       └── todos.dto.go            # Request/response shapes + validation tags
│
└── shared/
    ├── guards/
    │   └── auth.guard.go           # JWT auth guard stub
    └── errors/
        └── errors.go               # App-specific error constructors
```

This layout is enforced by convention, not by the framework. Bast works with any directory structure as long as modules are registered in `main.go`.

## Adding a module

Use the CLI to generate a new module. Run from the project root:

```bash
bast generate module payments
```

This creates `modules/payments/` with all 5 files **and** automatically adds the import and registration to `main.go`:

```
✓ Generated module/payments → modules/payments
  ↳ registered in main.go
```

The generated files follow the same pattern as the scaffolded Todo module — replace the stub repo and DTO with your actual data model.

## Graceful shutdown

The generated `main.go` includes graceful shutdown out of the box:

```go
quit := make(chan os.Signal, 1)
signal.Notify(quit, syscall.SIGINT, syscall.SIGTERM)

go func() {
    if err := app.Listen(); err != nil {
        slog.Error("server error", "err", err)
    }
}()

<-quit
ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
defer cancel()
app.Shutdown(ctx)
```

On `SIGINT` or `SIGTERM`:
1. The server stops accepting new connections
2. In-flight requests are drained
3. `OnShutdown` hooks run in reverse module registration order
4. The process exits cleanly

## Environment configuration

Use `bast.LoadConfig[T]()` to load typed config from environment variables:

```go
type AppConfig struct {
    Port        int    `env:"PORT"         default:"8080"`
    DatabaseURL string `env:"DATABASE_URL"  required:"true"`
    JWTSecret   string `env:"JWT_SECRET"    required:"true" secret:"true"`
    Env         string `env:"APP_ENV"       default:"development"`
}

cfg, err := bast.LoadConfig[AppConfig]()
if err != nil {
    // prints every missing required variable — not just the first one
    os.Exit(1)
}
```

Missing required variables are all reported in a single error so you fix them in one deploy cycle, not one at a time. See [Configuration](features/config) for the full reference.
